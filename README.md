# Spottr — Official Web Landing Page & APK Download

Official web landing page and Android APK download portal for **Spottr** — Your AI-Powered Workout Partner & Gym Community.

## Features

- **Direct Android APK Download:** One-tap download of `spottr.apk` (41.5 MB) directly from the website.
- **Bento Grid Showcase:** Interactive highlights of 1,000+ video workouts, Gym Bot AI coach, and workout partner discovery.
- **Zero Configuration Hosting:** Ready for instant 1-click deployment on [Vercel](https://vercel.com) or GitHub Pages.
- **Optimized Download Headers:** Custom `vercel.json` headers to deliver `.apk` files as native Android installer downloads.

## Deployment

### Vercel (Recommended)
1. Push this repository to GitHub as `VirakSok18/spottr_landing`.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select `spottr_landing` and click **"Deploy"**.
4. Your site will immediately be live at `https://spottr-landing.vercel.app` (or custom domain).
